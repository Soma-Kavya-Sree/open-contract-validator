# 🚀 Open Contract Validator

AI-powered legal contract analysis platform that detects risk levels, bias distribution, and suggests optimized clause rewrites in real-time.

---

## 🔍 Overview

Open Contract Validator analyzes uploaded PDF contracts and:

- Detects High / Medium / Low risk clauses
- Calculates overall security score
- Shows bias distribution (Employee vs Employer favoring)
- Provides AI-based clause improvements
- Displays interactive dashboard with animated metrics

Designed for hackathon-grade presentation with modern UI and explainable AI outputs.

## 📊 How It Works

1. User uploads a PDF contract  
2. Backend processes clauses  
3. Risk classification logic applied  
4. Bias analysis calculated  
5. Results returned as structured JSON  
6. Frontend visualizes insights interactively
